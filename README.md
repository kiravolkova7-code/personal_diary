# Личный дневник (Personal Diary)
## Описание
Веб-приложение для ведения личного дневника, разработанное на `Python` с использованием фреймворка `Django`. 

Сервис позволяет пользователям безопасно регистрироваться, создавать и управлять личными записями в современном 
адаптивном интерфейсе. 

Проект полностью контейнеризирован с помощью `Docker`, использует `PostgreSQL` для хранения 
данных и `Redis` для работы фоновых задач.

## Функционал
* Регистрация и аутентификация: 
Пользователи могут зарегистрироваться, войти в систему и выйти из неё.
* Управление записями:
Создание новых записей через веб-форму.
Редактирование существующих записей (доступно только автору записи благодаря проверке прав доступа).
Удаление ненужных записей.
* Просмотр записей:
Главная страница со списком всех личных записей пользователя.
Страница детального просмотра отдельной записи.
* Поиск по записям: Фильтрация списка записей по заголовку или содержимому непосредственно в интерфейсе сайта.
* Администрирование: Полная интеграция с админ-панелью `Django` для управления пользователями и записями.
* Фоновые задачи: Обработка асинхронных операций (например, рассылок) через `Celery` и `Redis`.

## Установка и запуск
Проект настроен для запуска в изолированной среде с помощью `Docker Compose`.

1. Клонируйте репозиторий и перейдите в ветку `develop`:
```
git clone https://github.com/kiravolkova7-code/personal_diary.git
cd personal_diary
git checkout develop
```
2. Настройте переменные окружения. Скопируйте шаблонный файл `.env.template` в рабочий файл `.env`.

3.  Откройте файл `.env` и заполните обязательные поля надежными значениями:

`SECRET_KEY`: Сгенерируйте новый ключ командой 
```
python manage.py shell -c 'from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())'.
```
`DEBUG`: Установите `False` для продакшена.

`DB_NAME`, `DB_USER`, `DB_PASSWORD`: Укажите данные для подключения к базе данных.

4. Соберите образы и запустите контейнеры:

```
docker-compose up --build -d
```
5. Примените миграции базы данных (если они не применились автоматически при старте контейнера):

```
docker-compose exec web python manage.py migrate --noinput
```
6. Создайте суперпользователя для доступа к админке:

```
docker-compose exec web python manage.py createsuperuser
```
Приложение будет доступно по адресу http://62.84.120.41:8080. Админ-панель — http://62.84.120.41:8080/admin.
7. Для остановки сервисов выполните команду:


```
docker-compose down
```
## Использование
После регистрации и входа в систему пользователь попадает на главную страницу со списком своих записей. 

Чтобы добавить новую запись, нажмите кнопку «Новая запись», заполните заголовок и текст, затем сохраните.
Каждая запись в списке имеет кнопки редактирования и удаления. При нажатии на заголовок открывается подробный просмотр.
Поиск осуществляется через поле ввода в верхней части страницы. Результаты фильтруются в реальном времени.
Визуальный интерфейс построен на `Bootstrap 5`, что обеспечивает корректное отображение на десктопах, планшетах и смартфонах.
## Тестирование
Проект содержит набор тестов для проверки бизнес-логики приложения.

Запуск локальных тестов:

```
docker-compose exec web pytest entries/tests/
```

Автоматическое тестирование (`CI`):

В проекте настроены `GitHub Actions` (`.github/workflows/ci.yml`). Пайплайн автоматически запускается при каждом пуше или создании `Pull Request`. 
Он выполняет следующие шаги:

* Проверка кода линтером `Flake8`.
* Запуск тестового набора `Pytest`.
* Сборка `Docker`-образа.
